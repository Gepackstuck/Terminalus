# Terminalus

macOS-приложение: несколько терминалов (для Claude Code) во вкладках одного окна + режим сетки.
Swift/AppKit + SwiftTerm (vendored, `Vendor/SwiftTerm`, v1.20.0, с нашим патчем в `scrollWheel`).

- Сборка: `./build.sh` (или `./build.sh run`). SwiftPM не используется.
- Иконка: `swift scripts/make_icon.swift <dir.iconset>` + `iconutil -c icns`, результат — `Resources/AppIcon.icns`.

## Правило: история версий
После каждой итерации работы с пользователем:
1. добавь запись в начало `Resources/CHANGELOG.md` (новая версия, дата, список изменений человеческим языком);
2. подними версию в `Resources/Info.plist` (CFBundleShortVersionString / CFBundleVersion).
Этот файл показывается в окне «О Terminalus».

# Состояние проекта (сводка для нового сеанса)

Версия на момент записи: **0.19.0**. История — `Resources/CHANGELOG.md`, git-лог, `README.md` (там же возможности и горячие клавиши).

## Что умеет приложение
- Вкладки + режим сетки (`GridView`/`GridLayout`: дерево разбиений, перетаскивание шапок, границы тянутся мышью, предпросмотр места вставки).
- «Стопка» закреплённых вкладок слева (`PinnedStackView`) и **архив**: закреплённые вкладки без активности 40 мин засыпают (процессы завершаются), просыпаются по клику (`claude --resume <id>` и т. п.). При перезапуске приложения закреплённые вкладки поднимаются лениво.
- Статусы вкладок (работает / ждёт ответа / завершено / в архиве) — по спиннеру в заголовке, «настоящему» выводу и тексту запроса разрешения; уведомления и бейдж в Dock.
- **Агенты** (`Agents.swift`, `AgentsWindow.swift`): профили Claude Code, Codex, Gemini CLI, opencode, Aider + свои; вопрос при первом запуске; агент, запущенный вручную, определяется по процессу (`KERN_PROCARGS2`) и запоминается за вкладкой.
- Лимиты и модель Claude — из `statusLine` (`Limits.swift`): скрипт в `~/Library/Application Support/Terminalus/statusline.sh`, данные по вкладкам в `tabs/<TERMINALUS_TAB_ID>.json`. Виджет лимитов скрыт, если Claude не используется.
- Питомцы Тян и Бэн в строке заголовка (`CatView`, пиксельный `PixelArt` и векторные `CatArt`/`DogArt`; меню «Terminalus → Питомцы»; режим 15 кадров/с).
- Цветные бейджи папок (`FolderBadge`, разбор camelCase), цветные метки вкладок, шрифт отдельно для каждой вкладки, вставка пути/скриншота, macOS-сочетания редактирования.

## Как собирать и проверять
- `./build.sh` (без SwiftPM; `ARCHS="arm64 x86_64"` — универсально; цель macOS 13). SwiftTerm пересобирается сам при правке `Vendor/`.
- **Экран и приложение пользователя.** Прав на скриншоты экрана нет. Интерфейс проверяем отрисовкой настоящих вьюх в память: `./scripts/make_screenshots.sh` (демо с вымышленными данными, `scripts/demo/main.swift`), плюс небольшие тестовые программы (компилируем нужные исходники + `libSwiftTerm.a` из `build/obj/<arch>`, подменяемые часы у `CatView.clockOverride`).
- **Не перезапускать запущенное приложение пользователя** — это обрывает его сеансы Claude (процессы дочерние). Собрать → сказать «⌘Q и откройте build/Terminalus.app». Найти процесс: `ps | grep Terminalus.app/Contents/MacOS` (`pkill -x` не находит).
- zsh не разбивает `$VAR` со списком файлов на слова — использовать `${=VAR}`.
- Профилирование: `sample <pid> 3`, `top -pid`; бенчмарки — отдельные программы.

## Важные подводные камни (уже наступали)
- Панель вкладок **вне** области заголовка окна: иначе macOS сам тянет окно за вьюхи в заголовке.
- Metal-рендерер SwiftTerm работает, только если `Shaders.metal` лежит в ресурсах приложения (копирует `build.sh`).
- `terminate()` у `LocalProcess` отменяет слежение за процессом → вручную `waitpid`; закрытие pty завершает и `claude`.
- Фон терминала (слой) не попадает в `cacheDisplay` — в демо-скрипте подкладывается вручную.
- Чтение `statusLine`: команда в `settings.json` в кавычках (путь с пробелом), скрипт ничего не печатает.
- У SwiftTerm `keyDown`, `scrollWheel`, `draw` — `public override`, из другого модуля не переопределить; правки — только патчем в `Vendor/` (описан в `Vendor/PATCHES.md`).

## Договорённости с владельцем (важно)
- **Вопрос ≠ просьба.** На «а можно ли…», «как будет работать…» — отвечать словами и ждать явного «делай». Перед крупной работой по идее — сначала рассказать, как будет.
- Коммитить и пушить каждое изменение (см. «Правило: git»). Отвечать по-русски.
- **Никаких личных данных** владельца в репозитории, картинках, README и в этом файле: почта и ФИО из глобального git, названия его рабочих проектов и папок, пути с именем пользователя. Скриншоты — только с вымышленными данными. В **истории git** остались старые картинки с личными названиями; переписать историю (force push) можно только с согласия владельца — предложено, ответа пока нет.
- Установщики (`.dmg`, автообновление) отложены «до доработки приложения»; черновики — `build.sh` (мультиархитектура), `scripts/release.sh`, `scripts/install.sh`.
- Панель плана агента была сделана и **удалена** (у используемых агентов нет сохранённого плана) — не возвращать без запроса.
- Тратить лимит осознанно: длинные сеансы дорогие (каждый шаг пересылает весь контекст). Для новых крупных задач — свежий сеанс.
