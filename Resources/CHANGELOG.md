## 0.18.0 — 13.11.2026

План читается из расшифровки сеанса Claude Code (TodoWrite, ExitPlanMode); если плана нет, панель объясняет почему
- Убрана всплывающая подсказка при наведении на окно в сетке

## 0.17.0 — 13.11.2026
- Поддержка разных агентов, не только Claude: при первом запуске приложение спрашивает, каким агентом вы пользуетесь; агент, запущенный вручную в любой вкладке, определяется по процессу и запоминается за этой вкладкой (метка агента на вкладке и в шапке окна сетки; сеанс продолжается нужной командой после архива и перезапуска)
- Окно «Terminalus → Агенты…»: Claude Code, Codex, Gemini CLI, opencode, Aider и свои агенты; команды запуска и продолжения сеанса редактируются; меню «Новая вкладка с…»
- Виджет лимитов скрыт, если Claude Code не используется
- В README — картинки с настоящими видами приложения (сетка, свободная раскладка, агенты) на вымышленных данных; скрипт `scripts/make_screenshots.sh`

## 0.16.1 — 13.11.2026
- Оптимизации: запись состояния вкладок объединяется в одну (раньше писалась на каждое событие), перекладка сетки при перетаскивании границ больше не форсируется на каждое движение мыши, шрифты питомцев и буквы бейджей кэшируются, таймеры допускают объединение пробуждений (меньше энергии в простое)

## 0.16.0 — 13.11.2026
- Исправлено главное по производительности: Metal-рендерер (отрисовка терминалов на GPU) на самом деле не включался — не хватало файла шейдеров в приложении, и всё рисовалось на процессоре; теперь шейдер кладётся в сборку. Переключатель «Отрисовка терминалов на GPU (Metal)» в меню на случай проблем
- «Архив»: закреплённые вкладки, к которым не прикасались 40 минут (и в которых Claude/оболочка ничего не делают), засыпают — процессы завершаются, память освобождается, вкладка и бейдж остаются (кружок ☾ в списке). По клику вкладка поднимается за 2–5 секунд: оболочка в той же папке и `claude --resume <id сеанса>`. Обычные вкладки никогда не усыпляются. Вручную: меню вкладки → «Отправить в архив сейчас» / «Разбудить». После перезапуска приложения закреплённые вкладки тоже поднимаются лениво — по клику, а не все сразу
- Раздел «Питомцы» в меню Terminalus: показ в заголовке, пиксельный стиль, экономный режим (15 кадров в секунду, включён по умолчанию), «Позвать поиграть»

## 0.15.0 — 13.11.2026
- «Стопка» закреплённых вкладок слева: показана одна закреплённая вкладка — цветным бейджем с полным названием папки и статусом; остальные закреплённые спрятаны в список, который открывается стрелкой со счётчиком справа. Точка на углу стрелки сообщает, что у спрятанной вкладки есть событие (ждёт ответа или закончила). Так можно держать открытыми десятки вкладок, не занимая места
- Бейджи папок различаются лучше: для одного слова теперь две буквы («terminalus» → Te, «tvclean» → Tv, «vibecode» → Vi), палитра расширена до 14 цветов
